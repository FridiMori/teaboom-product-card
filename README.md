# Teaboom.ru — карточка товара «Ананасовый улун»

Тестовое задание: верхняя часть карточки товара.

## Запуск
Установка не нужна: откройте `index.html` в браузере.
(Шрифт Open Sans подгружается с Google Fonts; без интернета сработает запасной Arial.)

Правка стилей: `npm i -g sass`, затем `sass --watch scss/style.scss css/style.css`.

## Структура
- `index.html` — разметка (article, figure, fieldset с radio для фасовок, form)
- `scss/style.scss` — точка входа, подключает паршалы через `@use`
- `scss/partials/`
  - `_colors.scss` — вся цветовая гамма
  - `_var.scss` — шрифт, радиус, миксины (`hover`, `focus`, брейкпоинты `sm` 560 / `md` 768 / `lg` 1200 px)
  - `_general.scss`, `_titles.scss`, `_btns.scss` — база, заголовок, кнопки
  - `_original.scss` — копия карточки с оригинального сайта для сравнения
  - `_product.scss`, `_favorite.scss`, `_about.scss`, `_packs.scss`, `_price.scss` — блоки нашей карточки
  - `_original.scss` — копия оригинальной карточки и подписи вариантов
- `css/style.css` — скомпилированный CSS
- `js/script.js` — фасовки, избранное, кнопка «В корзину» (vanilla JS)
- `images/` — фото товара

## Что реализовано
- Смена фасовки меняет цену, старую цену, процент скидки, артикул и выбранное состояние
- Данные фасовок лежат в `data-*` атрибутах радиокнопок, доступно с клавиатуры
- «В корзину»: обычное, hover, focus и «Добавлено» после клика (корзины нет)
- Сердечко: hover и состояние «в избранном» (`aria-pressed`), чего не было в ТЗ
- Адаптив: 1440 / 768 / 375 px. Подход mobile-first (min-width). На телефоне одна колонка, фасовки сеткой 2×2, кнопка на всю ширину; от 560 px фасовки в ряд; от 768 px две колонки
- `prefers-reduced-motion`, видимый фокус, `aria-live` для цены
